# Callouts Markdown Generator

Una herramienta visual e interactiva para aprender, generar y copiar **GitHub Markdown Callouts** de forma rápida y sencilla.

Perfecta para documentación, README.md, wikis, blogs técnicos y cualquier proyecto que utilice Markdown.

---

## ✨ Características

* 📖 Guía completa sobre los Callouts de GitHub.
* 🎯 Explicación detallada de cada tipo.
* 💡 Ejemplos prácticos listos para usar.
* ⚡ Generador interactivo de código Markdown.
* 👀 Vista previa en tiempo real.
* 📋 Copiar código con un solo clic.
* 🎨 Interfaz moderna y responsive.
* 📱 Compatible con móviles y escritorio.
* 🇪🇸 Totalmente en español.

## 🎯 Objetivo

Este proyecto fue creado para ayudar a desarrolladores, escritores técnicos y usuarios de GitHub a comprender fácilmente cómo funcionan los Callouts de Markdown y generar el código correcto sin necesidad de memorizar la sintaxis.

La herramienta combina aprendizaje, ejemplos prácticos y generación automática de código en una única interfaz simple y accesible.

---

## 📸 Funcionalidades

* Visualización de los cinco tipos de Callouts.
* Explicación detallada de cuándo utilizar cada uno.
* Ejemplos renderizados.
* Código Markdown listo para copiar.
* Generador dinámico de Callouts.
* Vista previa en tiempo real.
* Diseño moderno y minimalista.
* Totalmente responsive.
