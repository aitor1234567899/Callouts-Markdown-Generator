Cómo escribirlos

      
La sintaxis paso a paso

      
Los callouts usan la sintaxis de blockquote de Markdown, extendida con una etiqueta especial.

    

    

      

        
1 Estructura básica

        
Comienza con > seguido de
          [!TIPO]. El contenido va en las líneas siguientes con >.
        

        
> [!NOTE]  
> Tu mensaje aquí.  

      

      

        
2 Saltos de línea

        
Añade dos espacios al final de
          cada línea para crear un salto de línea explícito.

        
> [!TIP]  
> Primera línea.  
> Segunda línea.  

      

      

        
3 Varios párrafos

        
Para párrafos separados añade una línea vacía
          con solo > entre ellos.

        
> [!IMPORTANT]  
> Primer párrafo.  
>
> Segundo párrafo.  

      

      

        
4 Compatibilidad

        
Funciona de forma nativa en GitHub. Para
          Next.js y otros entornos usa el plugin rehype-github-alerts.

        
# next.config.mjs
import { rehypeGithubAlerts } 
  from 'rehype-github-alerts'
