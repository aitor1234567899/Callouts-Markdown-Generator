Cómo escribirlos

    
La sintaxis paso a paso

    
Los callouts usan la sintaxis de blockquote de Markdown, extendida con una etiqueta especial.

  

  

    

      
1 Estructura básica

      
Comienza con > seguido de [!TIPO]. El contenido va en las líneas siguientes con >.

      
> [!NOTE]  
> Tu mensaje aquí.  

    

    

      
2 Saltos de línea

      
Añade dos espacios al final de cada línea para crear un salto de línea explícito.

      
> [!TIP]  
> Primera línea.  
> Segunda línea.  

    

    

      
3 Varios párrafos

      
Para párrafos separados añade una línea vacía con solo > entre ellos.

      
> [!IMPORTANT]  
> Primer párrafo.  
>
> Segundo párrafo.  

    

    

      
4 Compatibilidad

      
Funciona de forma nativa en GitHub. Para Next.js y otros entornos usa el plugin rehype-github-alerts.

      
# next.config.mjs
import { rehypeGithubAlerts } 
  from 'rehype-github-alerts'

Buenas prácticas

    
Úsalos bien

  

  

    

      
01

      
No abuses de ellos

      
Si todo es importante, nada lo es. Reserva los callouts para información realmente crítica o útil.

    

    

      
02

      
Elige el tipo correcto

      
Usa WARNING y CAUTION solo cuando haya un riesgo real, no para información general.

    

    

      
03

      
Sé conciso

      
Los callouts funcionan mejor con textos cortos y directos. Para contenido largo usa párrafos normales.

    

    

      
04

      
Dos espacios al final

      
Añade dos espacios al final de cada línea para crear saltos de línea explícitos en el renderizado.
